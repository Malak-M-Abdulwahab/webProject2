# Perfume shopping store

This is the fourth project I took in SEF Academy. The academy focuses on Full stack. The languages I used are html, css, and JavaScript. It was assigned to me after about 48 lectures.

The second and third are not posted on github because they are very minor projects. I like to keep here the projects that are generally bigger.

I stuck with the same theme, images, and colours of the last project. I wanted to focus more on my JavaScript abilities, as this project mainly focuses on the JavaScript portion I took after HTML and CSS.

I own none of the photos used in this website and the one before. I am simply using them as a mock example for a website, only as practice.

## HTML and CSS

## JavaScript

It was certainly the hardest obstacle I've had to overcome so far. My problem solving skills have always been good but now I have to use different materials for different problems and solutions.

I have been studying a little bit of PHP and SQL that I've tried adding to my website, but for the sake of the course I'm taking I removed them. Hopefully I will get to use them in the upcoming projects when we start backend.

The project while impressive needs alot more work and refining, there are some tiny bugs that should be fixed regarding JavaScript and I will continue to work on it as I learn further about JavaScript.
